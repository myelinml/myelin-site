the idea

one model. one machine. one native
program.

Myelin compiles each model into a native binary for the machine it runs on. The compiler sees the whole model graph and removes the parts it does not use.

[2] the kernel language

a small language
that maps to
the hardware.

no garbage collector. no runtime library.
every kernel compiles to C and to Metal.

kernels/core.mkMKL v1
kernel rmsnorm(y: out f32[T, D], x: f32[T, D],
               w: f32[D], T: i32) {
    par for t in 0..T {
        let ss = 0.0;
        for i in 0..D { ss += x[t, i] * x[t, i]; }
        let r = rsqrt(ss / f32(D) + EPS);
        for i in 0..D { y[t, i] = x[t, i] * r * w[i]; }
    }
}
